# Painterly smiley

A flat yellow smiley on textured cream paper, created in Blender with irregular
paint strokes and charcoal features.

- `smiley.blend` — editable scene; opens with the finished image displayed.
- `smiley.png` — 1024 × 1024 image export.
- `create_smiley.py` — Blender Python script used to generate the artwork.

The scene separates paper, yellow brushwork, and facial features into named
collections. Switch the main editor to **3D Viewport** to edit the flat shapes.
The camera is orthographic and the pigment materials use emission for a 2D look.
