Modify a course visualization using an instructor-provided dataset, apply your own data to an example, or explore another data-driven variation allowed by the brief.

## Work to complete

- Create your visualization in `sketch.js`.
- Include shareable data in `assets/` and document its source and meaning.
- Save screenshots and process images in `documentation/`.
- Commit and push the work in `assignments/MiniAssignment4/`.

Keep private data in `local-data/`; it is ignored by Git and excluded from the static build. Describe any local setup needed to run with private inputs.

## Your documentation

Replace these prompts with your own account:

- **Data and credit:** What does each record represent? Where did it come from?
- **Mapping:** How do values affect visual properties?
- **Changes:** How did you adapt the starting example?
- **Reflection:** What can the visualization show, and what does it leave out?
