# Final Project

[Assignment brief](https://csvad26.github.io/course_site/assignments/final-project)

**Status: scaffold — no proposal has been written yet.**

The brief offers several directions: a computational creative tool, a series of generative works, a programming library, or an extension of a previous assignment. Check the full brief for the requirements of your chosen direction and current deadlines.

## Proposal prompts

Write your proposal here or in a linked file in `assignments/FinalProject/`:

- What will you make, and why?
- Which project option will it meet?
- What are the initial technical and creative questions?
- How will you judge the result?
- If collaborating, how will you divide the work?

Revise the proposal after peer and instructor feedback. These prompts are a scaffold, not a completed proposal.

## Final materials

- Full source code on GitHub.
- A presentation or demonstration for the class critique, with materials submitted as directed by the brief.
- Approximately **1,000 words** describing the goal, result, challenges, limitations, and possible next steps.
- A separate **250–500 word** course self-assessment, submitted as directed.

The brief lists Google Drive for the written reflection and presentation materials, and also calls for presentation materials on GitHub. Follow current instructor guidance on submission locations and dates.

## Documentation to develop

Add your own project description, run instructions, images, process notes, results, limitations, and credits. Use `assets/` for shareable inputs and `documentation/` for screenshots, example works, and process images. Keep private materials out of the repository and build.
