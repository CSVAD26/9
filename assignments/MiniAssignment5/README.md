# Mini Assignment 5 · Sensor Input

[Assignment brief](https://csvad26.github.io/course_site/assignments/mini-assignment-5) · [Course examples](https://github.com/CSVAD26/code_samples/tree/main/Arduino)

**Status: starter — replace this line when you begin.**

Work in a pair to send data from your assigned sensor through Arduino to Processing or p5.js, then use that data to change visual properties.

## Work to complete

- Add the Arduino sketch and the receiving visualization to this folder.
- Document the sensor, wiring, communication method, and software needed to run it.
- Describe what the sensor values change on screen.
- Save photographs, screenshots, or a demonstration recording in `documentation/`.
- Credit your partner's contribution and commit and push the work in `assignments/MiniAssignment5/`.

This p5 starter does not configure a sensor or serial connection. Follow the course examples for the hardware and communication setup you choose.

## Your documentation

Replace these prompts with your own account:

- **Team and contributions:** Who worked on each part?
- **Setup:** Which hardware, connections, and software are required?
- **Data mapping:** How are sensor readings converted to visual changes?
- **Reflection:** How did you handle noise, range, or connection problems?
