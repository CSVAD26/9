# Project 2 · Data Portrait

[Assignment brief](https://csvad26.github.io/course_site/assignments/project-2)

**Status: starter — replace this line when you begin.**

Build an interactive visualization of one or more personal datasets. Engage with acquisition, parsing, cleaning, and representation, and give viewers a way to explore or filter the data. Use visual design to communicate a coherent narrative or aesthetic.

## Deliverables

- Commented source code on GitHub.
- A working application for the class review.
- This README expanded to at least **500 words** describing functionality, design principles, process, reflections, and outcomes.

Sensitive source data is not required for submission. Keep private inputs in `local-data/`, which is ignored by Git and excluded from `dist/`. Set up loading locally as needed; provide a safe sample in `assets/` if you want others to run the shared version. Document any steps needed to reproduce it.

## Write your project account

Replace these prompts with your own writing and images:

- **Question:** What aspect of your experience does the portrait explore?
- **Data:** How did you collect, parse, and clean it? What did you exclude?
- **Representation:** How do values become visual properties?
- **Interaction:** How can a viewer investigate the data?
- **Process and review:** What changed through development and peer feedback?
- **Outcomes:** What does the portrait reveal, and what are its limitations?

Store screenshots and process images in `documentation/`; review them for private information before sharing. Credit datasets, tools, and code sources.
