# Project 1 · Drawing Tool

[Assignment brief](https://csvad26.github.io/course_site/assignments/project-1)

**Status: starter — replace this line when you begin.**

Create a drawing tool that produces visible marks, lets its operator choose color, and imposes at least one aesthetic constraint. Guidance must be available in the tool itself so someone can use it without verbal instructions.

## Deliverables

- Commented source code on GitHub.
- A working application for the class review.
- This README expanded to at least **500 words** describing functionality, design principles, process, reflections, and outcomes.

Keep inputs in `assets/` and process images and example drawings in `documentation/`. Include credits for adapted code or other materials.

## Write your project account

Replace these prompts with your own writing and images:

- **Concept:** What kinds of drawings should the tool encourage?
- **Use:** What controls and interactions does it provide?
- **Design:** How does the aesthetic constraint shape the result?
- **Process:** What did you try, change, and learn?
- **Review:** What did you observe when a classmate used it?
- **Outcomes:** What works well, what is limited, and what would you improve?
