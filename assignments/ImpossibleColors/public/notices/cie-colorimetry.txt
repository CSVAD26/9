The original CSV bytes are unmodified. The application parses their numeric
values, selects every fifth observer row for its 5 nm path, uses a 1 nm
trapezoidal reference, and normalizes relative illumination by visible Y.
Finite-volume cell integration uses piecewise-linear observer functions.
These processing steps are modifications to derived representations, not
changes to the original files. Preserve attribution and this license for
adapted data. The repository software license does not replace this data
license. No endorsement by CIE is claimed.

D65 ends at 830 nm. The separately authored equal-energy 300–1000 nm source
is normalized using the observer's visible-Y integral; it is not a measured
UV/NIR extension of D65. Interpolation adds no instrument resolution.

Exact source URLs, official-metadata URLs and SHA-256 checksums are in
data/cie/provenance.json in the source distribution.
